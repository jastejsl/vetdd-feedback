# July build updates

#### Image addition

Work to support images for the various entries in VetDD has begun. Images are being added for the already displayed parasites and protozoan first. Thereafter, images for bacteria and virus will be added too.

#### Search bar enhancement

The search bar has been upgraded to have the abiity to toggle filters. It was found that users were still searching directly in the search bar for species or categories and so, to ensure the user is still able to acquire the information they desire, the search bar now allows for this.

#### Research component

I am currently investigating how I could add the research component I have so long desired to exist in this app. More information will be shared once there is a tangible materialisation of the efforts.
